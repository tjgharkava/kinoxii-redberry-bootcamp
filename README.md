# Kino XII

Cinema booking web app built with Vanilla JavaScript and Vite.

**Live demo:** https://helpful-kitsune-e4ab04.netlify.app/

## Features

- Home page: hero slider, now playing, coming soon, recently viewed
- Sessions page with filters (venue, date, format, language, time of day), sorting and pagination
- Movie details page with sessions by date
- Search modal
- Registration and login (token-based), session restore via `/api/me`
- Profile page with avatar upload and preferred venue
- Booking modal with seat map (in progress)

## Tech stack

- Vanilla JavaScript (ES modules)
- Vite
- CSS (no frameworks)
- REST API: https://api.kinoxii.redberryinternship.ge/api

## Design

Implemented for a 1920x1080 viewport.
